# App Contador de Cliques

> Repositório didático: exercício prático de Android nativo com **Java**, desenvolvido e aplicado em sala de aula pelo Prof. Fabricio Curvello.

## Sobre o projeto

Aplicativo que conta quantas vezes o botão foi tocado e mostra o número na tela.

## Contexto acadêmico

Exercício aplicado em sala de aula, usado como prática guiada com os alunos.

## O que o app faz

- Cada toque no botão incrementa o contador e atualiza o `TextView`.
- Um `Toast` mostra o total de cliques a cada toque.

## Conceitos trabalhados em aula

- Atributo `android:onClick` no layout XML ligado a um método Java
- Variáveis de instância e incremento
- Mensagens rápidas com `Toast`

## Tecnologias

- **Java**
- **Android SDK** (Android Studio)
- **Gradle**
- `minSdk 27` / `compileSdk 34`

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/fabcurvello/AppContadorCliques.git
   ```
2. Abra a pasta no **Android Studio** e aguarde a sincronização do Gradle.
3. Execute em um emulador ou dispositivo físico com Android compatível com a API 27 ou superior.
